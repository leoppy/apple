# 环境变量配置工具

从 `.env` 文件读取环境变量配置，帮助快速设置系统环境变量。

## 使用方法

### 1. 准备配置文件

```bash
# 在仓库根目录创建 .env 文件
cd apple
cp .env.example .env
# 编辑 .env 填写你的配置
```

### 2. 运行工具

```bash
cd 50_ConfigToos/02_env
python env_config.py
```

### 3. 预览模式（不实际修改）

```bash
python env_config.py --dry-run
```

## 功能特性

- ✅ 实时读取系统环境变量状态
- ✅ 支持单选、批量、全选配置
- ✅ 跨平台（Windows/macOS/Linux）
- ✅ 配置持久化到系统环境变量

## 操作说明

### 菜单选项

1. **查看当前环境变量状态** - 显示所有变量及设置状态
2. **选择性配置环境变量** - 通过序号选择要配置的变量
3. **配置所有环境变量** - 一键配置所有变量
4. **配置未设置的环境变量** - 只配置当前未设置的变量

### 选择配置示例

```
请输入: 1 3 5        # 配置第 1、3、5 个
请输入: 1,3,5        # 同上，逗号分隔
请输入: all          # 配置全部
请输入: u            # 只配置未设置的
```

## 平台说明

| 平台 | 配置方式 | 生效方法 |
|------|---------|----------|
| **Windows** | `setx` 命令（用户环境变量） | 重启终端或应用 |
| **macOS** | 写入 `~/.zshrc` | `source ~/.zshrc` 或重启终端 |
| **Linux** | 写入 `~/.bashrc` | `source ~/.bashrc` 或重启终端 |

## 安全提示

⚠️ 工具会将环境变量持久化到系统配置，Token 和密码等敏感信息会被写入系统环境变量，请确保操作系统安全性。
